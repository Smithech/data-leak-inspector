# Data Leak Inspector

Herramienta para detectar fugas de datos.

## Instalación

```bash
pip install data-leak-inspector
```

!!! note "Tip"

    Usa un entorno virtual para evitar conflictos de dependencias.

!!! warning "Cuidado"

    Nunca subas credenciales privadas a GitHub.


=== "pip"

    ```bash
    pip install data-leak-inspector
    ```

=== "uv"

    ```bash
    uv pip install data-leak-inspector
    ```
